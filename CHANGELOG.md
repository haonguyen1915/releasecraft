## v0.3.0-rc.1 – 2025-11-16

Introducing enhanced CLI features and AI-powered release notes generation in version 0.3.0-rc.1.

### Highlights
- Added a new version source option to the CLI for improved version resolution flexibility.
- Introduced an auto-commit feature in the CLI to streamline the release process without user prompts.
- Implemented AI-powered generation of commit messages and release notes, enhancing automation and accuracy.
- Enhanced provider configuration handling for better integration and usability.
- Enabled the inclusion of diffs for significant commit types, improving context in release notes.
